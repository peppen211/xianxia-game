# 新原型 0.1

這是與舊版 HTML 分離的 TypeScript + Vite 原型，尚未部署，也尚未完成瀏覽器或手機實測。

## 本機執行

需要 Node.js 版本相容的 npm 環境：

```bash
npm install
npm run dev
```

## 驗證

```bash
npm test
npm run build
npm run preview
```

## 目前包含
- 新角色初始狀態與手機優先介面。
- 自動修煉與時間戳進度結算。
- 最多 12 小時離線收益原型。
- 達標後手動突破的原型流程。
- 一個探索點、一項靈草資源及一次性事件旗標。
- 獨立的版本化本機存檔 key：`xianxiaPrototypeSaveV1`。
- 初步離線結算測試案例。

## 明確限制
- 突破門檻、修煉倍率與離線上限都是原型暫定值，並非已考證的原著規則。
- 尚未完成完整境界、功法、戰鬥、宗門、秘境、主線與圖鑑。
- 尚未加入存檔匯出／匯入及舊版存檔遷移。
- 尚未執行 `npm install`、`npm test`、`npm run build` 或真實手機瀏覽器測試；不可標記為測試通過。
- 本原型的存檔與舊版遊戲分離，重置本原型不應影響舊版存檔。
