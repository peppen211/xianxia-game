# 《凡人修仙・自由放置 RPG》境界體系規格紀錄 v2.1

## 文件狀態
- 階段：原著境界體系與修煉規則規劃
- 狀態：架構草案已建立；原著細節仍待逐項核實
- 下一階段：突破與修煉規則表
- 適用開發版本：3.3
- 保護規則：穩定版 3.2 不得修改
- 注意：本文件只記錄規劃，不代表遊戲程式已實作相關系統。

## 專案核心原則
1. 以《凡人修仙傳》小說原著為主要依據；動畫只作視覺參考，不要求動畫演出。
2. 玩家是獨立主角；韓立維持原著中的身分與人生線。
3. 遊戲以自由放置修仙為核心：平常自動修煉、離線計算收益；達到突破條件後提醒玩家，由玩家決定何時嘗試。
4. 除死亡及必要的重大遊戲機制外，修仙規則盡量忠於原著。
5. 原著明確記載的內容照原著；存在差異或尚未確認的內容標記待核對；遊戲平衡用數值不得冒充原著設定。
6. 遊戲以文字事件為主，圖片主要用於頭像、圖鑑、場景與背景。

## 每個境界需整理的資料欄位
- 正式境界名稱與原著依據
- 小境界及特殊階段
- 修煉方式與修為進度
- 突破前置條件與瓶頸
- 丹藥、功法、材料及特殊機緣
- 突破風險、失敗後果及天劫
- 壽元規則（只採用有可靠依據的內容）
- 地圖、人物、宗門、秘境與劇情解鎖
- 原著章節／可靠參考來源
- 確認狀態：已核實／待核對／遊戲自訂

## 後續工作順序
1. 逐項核對人界與靈界境界的小境界、特殊稱呼及原著依據。
2. 逐項核對仙界篇境界、仙竅、法則及其他特殊進階規則。
3. 建立各境界的突破與修煉規則表。
4. 建立世界、地圖、人物、秘境及主線劇情解鎖表。
5. 將已確認的規格整合到 3.3；先檢查及測試，不觸碰穩定版 3.2。
