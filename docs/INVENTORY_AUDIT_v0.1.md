# 儲物袋與物品系統盤點報告 v0.1

- 盤點日期：2026-10-26
- 盤點範圍：正式入口程式 `index.html`（GitHub `main` 分支）
- 盤點基準：程式內實際資料定義與操作函式；不以舊版進度說明代替程式核對。

## 一、入口與存檔安全

- 正式入口是根目錄 `index.html`；`src/` 下的 React 專案不是目前 GitHub Pages 直接遊戲入口。
- 程式畫面目前標示版本：`v6.6`。
- 存檔鍵：`nine_heavens_idle_v2`。
- 初始資料結構包含裝備、穿戴欄、古寶碎片、已持有古寶、法寶、啟用法寶欄、靈寵與材料資料。
- `inventory` 初始為空陣列，實際持有裝備由掉落、製作等遊戲流程加入；因此不能把初始清單誤報為玩家目前擁有物品清單。
- 本次未執行重置、清除、遷移或寫入玩家存檔。

## 三、裝備製作與資源規則

- `QI_GEAR_RECIPES` 共 20 筆煉氣期裝備配方。
- 配方會消耗材料並產生裝備；強化流程依等級增加材料消耗。
- 舊資源靈木、低階靈晶、凝氣草有相容性處理；新增材料另存於 `craftingMaterials`。
- 程式將金雷竹、庚精用作青竹蜂雲劍升級材料，並標註原作材料題材／遊戲化用途。
- 古寶碎片與一般煉器材料分開保存，不應互相替代。

## 四、目前可確認的分類圖鑑內容

- 裝備／器物分類說明：法器、法寶、符寶、仿製靈寶。
- 寶物分類說明：本命法寶、古寶、通天靈寶、玄天之寶。
- 原著典藏已整合在既有「分類圖鑑」中，至少包含金蚨子母刃及其他原作寶物條目。
- 分類圖鑑是考據／分類資料，不等同於玩家背包物品，也不代表該物件已能掉落、製作、裝備或使用。

## 五、第一輪發現與待辦

### 已確認
1. 儲物袋已具有五個主分類：裝備、古寶、靈寵、法寶、材料。
2. 古寶、法寶、靈寵與材料均有獨立資料定義，不是只有介面空殼。
3. 裝備清單是玩家狀態中的動態資料，不能只靠靜態目錄判定玩家擁有數量。
4. 原作名稱、原作用途與遊戲化效果已在部分資料中分開標註，但仍須逐條檢查。
5. 本次只做靜態程式盤點，尚未重新執行瀏覽器互動測試，因此不宣稱本輪功能回歸通過。

### 下一步（仍屬第 3 階段）
1. 逐一核對裝備模板、初始裝備、敵人掉落池、商店商品與配方的資料來源是否一致。
2. 核對所有古寶、法寶、靈寵條目的來源標籤，將「原作具名」「遊戲自創」「待核實」分清。
3. 在隔離測試狀態下測試五個分類切換、詳情、裝備操作、材料數量、合成／強化／分解與重載。
4. 只在上述盤點完成後，才補入缺少的原作物品資料；不因資料收錄而擅自讓物件進入掉落池或玩家存檔。
