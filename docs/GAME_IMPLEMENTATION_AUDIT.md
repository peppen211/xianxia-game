# 現有遊戲程式盤點報告（2026-10-23）

## 範圍
已讀取 main 分支兩份 HTML：`mortal-cultivation-rpg.html`（27,426 字元）及 `mortal-cultivation-rpg-3.3.html`（34,048 字元）。本報告是靜態源碼盤點，沒有執行瀏覽器、手機 Safari 或本機存檔測試。

## 版本比較
- 兩版共用核心資料結構、境界進度模型、主要分頁與修煉、突破、採集、戰鬥、存檔事件。
- 共同存檔 key 為 `mortalCultivationSaveV2`，使用 localStorage；離線收益最多計算 12 小時。
- 3.3 主要增加頂部修為進度條與快速狀態面板（境界、修煉狀態、修為、靈石、氣血）。
- 3.3 對已進入遊戲後切回前景的修為計算多了一段處理；需實測確認不會重複計算或漏算。
- 不能僅憑檔名判定 3.3 一定是最佳開發基礎。

## 實際已存在
- 單頁 HTML，內嵌 CSS／JavaScript，深色修仙風格與手機版版面設計。
- 角色入口；預設名稱「詠祺」、靈根「四屬性偽靈根」。
- 六個內容頁：角色、洞府、世界／探索、戰鬥、商店、背包；底部五個主要導覽按鈕，戰鬥另由入口進入。
- 修煉開關；修煉時每小時增加 10 點修為，再乘靈根倍率，四屬性偽靈根倍率為 0.78。
- 簡化境界顯示：凡人或練氣 N 層；修為門檻為 100 + level × 35；突破成功率固定 82%。
- 突破成功扣除門檻修為並提升 level；失敗扣除部分修為並減少氣血。
- 隨機採集草藥、靈石或修為。
- 單次簡化野狼戰鬥結算，取得修為、靈石與材料並扣氣血。
- localStorage 本機存檔、手動存檔、定時存檔、重置確認。
- 背景／重新載入時的離線修為計算，最多 12 小時，且存檔時角色必須正在修煉。

## 部分存在
- 境界只有 level 對應凡人／練氣層數的簡化顯示，突破上限 level 13；沒有完整人界、靈界、仙界資料與原著規則。
- 自動修煉有基本累積和離線計算，但進入遊戲時會把 cultivating 設為 false，未達到完整的永續放置體驗。
- 背包只顯示靈石、草藥、材料等少量數值，未見完整物品欄、裝備、法器或丹藥使用。
- 戰鬥只有單次簡化結算，並非完整戰鬥流程。
- 商店頁面存在，但坊市入口會提示「將在後續版本開放」，未見實際交易。
- 世界探索有採集與固定敘述，未見地圖、區域移動、秘境或事件條件。
- 存檔只在本機，沒有雲端同步。兩版共用 save key，跨版本相容性尚未驗證。

## 未發現
在這兩份檔案的現有源碼中，未看到功法系統、任務／劇情分支、原著人物互動、地圖／宗門／秘境解鎖、完整裝備與物品資料庫、壽元／天劫／心魔／仙竅／法則等境界機制、玩家獨立機緣與韓立各自劇情線、完整仙界篇進度、存檔匯出匯入或雲端備份。這只代表本次檢查的兩份檔案中未發現，不代表其他分支或歷史版本一定沒有。

## 待驗證
- iOS Safari／Android 瀏覽器的版面、觸控、滾動、安全區與字型。
- 新建、修煉、突破、採集、戰鬥、存檔、重載與重置全流程。
- 離線收益在背景、關閉分頁、重新開啟與切換版本時是否重複計算或漏算。
- localStorage 停用、空間不足或資料損壞時的處理。
- 兩版共用存檔 key 的相容性，以及 3.3 快速狀態 UI 在窄螢幕的穩定性。
- 突破成功率、修為與掉落數值是簡化遊戲設定，未核實為原著規則。

## 結論
目前兩份檔案是可互動的早期原型，已有基本介面、修為累積、本機存檔、簡單採集與單次戰鬥，尚不是完整自由放置修仙 RPG。本次沒有修改遊戲 HTML。下一步應彙整已確認玩法與未定案想法，再由使用者決定方向及版本策略。
