# xianxia-game

修仙 RPG 專案，保留舊版 HTML，並獨立開發手機優先的新原型。

## 免費遊玩

**手機版可玩入口：** https://peppen211.github.io/xianxia-game/

直接用 iPhone Safari 或其他現代瀏覽器開啟即可，不必安裝 App，也不需要付費工具。遊戲進度保存在目前裝置的瀏覽器中，建議定期到「設定」匯出 JSON 存檔備份。

目前入口版包含自動修煉、離線修為結算（最多 12 小時）、手動突破、山徑探索、靈石與靈草、道號設定、存檔匯出／匯入。這是持續開發中的遊戲原型，尚未代表完整遊戲；功法、宗門、秘境與戰鬥等系統會逐步擴充。修煉速率與境界門檻為原型假設，不代表原著正式設定。
