# xianxia-game

修仙 RPG 專案，保留舊版 HTML，並獨立開發手機優先的新原型。

## 免費遊玩

**新原型網頁：** https://peppen211.github.io/xianxia-game/

直接用 iPhone Safari 或其他現代瀏覽器開啟即可，不必安裝 App，也不需要付費工具。第一次開啟需要網路；完成快取後，部分功能可嘗試離線使用，實際離線狀況仍需在手機上測試。

注意：GitHub Pages 網址是公開可訪問的，沒有密碼保護。遊戲存檔目前保存在使用者的本機瀏覽器中，建議定期匯出備份。
